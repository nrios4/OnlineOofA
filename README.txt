README

This folder contains all of the R code and numeric results required to reproduce the analyses in the paper "Two-Phase Online OofA Experiments."

**************************************************************************************************
BEFORE RUNNING ANY FILES, RUN "OnlineOofA.Rproj" in RStudio. All directories are relative to the root folder of this project, and this is handled by the Rproject in RStudio.
**************************************************************************************************

FILE DESCRIPTIONS:

-- initial_design_m15_job_scheduling_n1_37.csv: This csv file contains the initial design used by Alg 3 in Section 4.
-- MakeTables1andB1.R: This R script can produce either Table 1 or Table B1.
-- MakeTable2.R: This R script produces Table 2.
-- MakeTableB2.R: This R script produces Table B2. 
-- OnlineOofA.Rproj: This is the R project. Run this first.
-- OnlineOofASource.R: Contains all custom R functions used throughout.
-- OnlineOofASec3.1.R: Contains the R code used to run the numerical analyses in Section 3.1.
-- OnlineOofASec3.2.R: Contains the R code used to run the numerical analyses in Section 3.2.
-- OnlineOofASec4.R: Contains the R code used to run the example in Section 4.
-- OnlineOofASensitivityAnalysis.R: Contains the R code used in the sensitivity analysis in Appendix B.
